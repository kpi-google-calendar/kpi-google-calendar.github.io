Які дані використовуються

Застосунок обробляє вибрану назву групи, відкриті дані розкладу з API КПІ та короткоживучий токен Google OAuth. Токен існує лише в оперативній пам’яті вкладки та не надсилається на сервер KPI Calendar.

Доступ до Google Calendar

Запитується вузький дозвіл calendar.app.created. Він дозволяє створити окремий календар і керувати подіями лише в календарях, створених цим застосунком. KPI Calendar не читає та не змінює інші календарі користувача.

Локальне зберігання

У локальному сховищі браузера зберігається лише ідентифікатор створеного календаря для повторного імпорту без дублювання. Розклад, токени та дані облікового запису на сервері не зберігаються.

Передавання третім сторонам

Дані не продаються й не передаються рекламним або аналітичним платформам. Браузер звертається безпосередньо до API КПІ та Google Calendar API. GitHub Pages може обробляти стандартні технічні журнали відповідно до політики GitHub.

Видалення даних і доступу

  • видаліть календар «Розклад … · КПІ» у налаштуваннях Google Calendar;
  • відкличте доступ KPI Calendar у налаштуваннях безпеки Google Account;
  • очистьте дані сайту у браузері, щоб видалити локальний ідентифікатор.
