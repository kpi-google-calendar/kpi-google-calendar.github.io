KPI Calendar

Умови використання

Оновлено 29 серпня 2026 року

Призначення

KPI Calendar безкоштовно переносить відкриті дані розкладу КПІ в окремий Google Calendar. Новий обліковий запис для користування сайтом не створюється.

Точність розкладу

Застосунок відображає дані, отримані з API КПІ на момент імпорту. Розклад може змінитися після імпорту, тому користувачеві слід повторити імпорт або перевірити важливе заняття на schedule.kpi.ua.

Відповідальність користувача

Користувач самостійно обирає групу, період імпорту та Google Account. Не слід використовувати застосунок для календаря іншої особи без її дозволу.

Доступність

Сервіс надається «як є». Робота може тимчасово залежати від доступності GitHub Pages, API КПІ та Google Calendar API.

Відкритий код

Код поширюється за ліцензією MIT і доступний у репозиторії GitHub.
